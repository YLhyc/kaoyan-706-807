# 2027 考研专业课双轨随身背诵手卷 · 807 与 706 独立专属研读平台

> **专注中文系考研专业课高分背诵与逻辑咬合**  
> 涵盖 **807 专业课（中国现当代文学与文学评论写作 · 20 题）** 与 **706 专业课（中国古代文学与古代汉语 · 16 题）** 全部 36 大核心高频考点，累计 72 条高品质音轨与 9,368 句毫秒打点时间戳。

---

## 🌟 核心特色与功能

### 1. 双轨并行背诵体系
- **【轨道一】考场直接答题完整版**：
  - 顶部考场规格条（题型、分值、建议用时、考场规范字数）。
  - 段落层次分明：【引论 · 立论破题】、【本论 · 各分论点】、【结语 · 总结升华】。
  - **论述中心句（Thesis Statement）突出高亮**：独家醒目朱红重点边框与徽标，一眼抓住核心得分点！
  - **学术核心关键词标红加粗**：书名、名家、关键文论概念与论据统一渲染为朱砂红粗体，重点分明。
- **【轨道二】内部逻辑咬合精解版**：
  - **全局审题与立意建构图谱**：四大维度导学问答（回答什么、立意高度、展开维度、逻辑递进）。
  - **【考场金句】原句卡**：朱红强调金句卡，醒目背诵。
  - **【名师逻辑咬合精解】卡**：温润纸质浅色卡片，剖析得分逻辑、扣分陷阱与思维递进脉络。

### 2. 官方精选通读音色
- 全库 100% 采用阿里百炼通义语音大模型 `qwen-audio-3.1-tts-flash` 官方音色 `longanlang_v3.1`（**龙安朗 · 清爽利落全段通读 Solo**），吐字清晰、气口沉稳自然，专为长时间沉浸式听读背诵打造。

### 3. 学术多样化字体体系
- 复用政治背诵手册同款学术字体，在顶部导航栏支持一键无缝切换：
  - **文人雅宋**（思源宋体 / Noto Serif SC）：典雅书卷，古朴沉静
  - **霞鹜温楷**（LXGW WenKai Screen）：手卷墨润，温润耐看，适合默诵
  - **现代精黑**（PingFang SC / 思源黑体）：清晰干练，专注高效
  - **典雅仿宋**（FangSong / 仿宋）：庄重严密，标准规范
- 支持字体偏好记忆，下次打开自动还原。

### 4. 毫秒级卡拉OK点读与三遍循环背诵模式
- **毫秒级卡拉OK聚光光晕**：播放时当前句自动以柔和光晕高亮，并在视窗内平滑居中保持可见。
- **单句点击即播 (Tap to Seek)**：正文任意句子点击即可毫秒级精准跳播。
- **单句三遍循环背诵 (3x Loop)**：底栏一键切换【三遍循环】与【全篇顺读】，每句朗读 3 遍后自动切入下一句，黄金踩分句深度印刻大脑。
- **多倍速调节**：0.85x ~ 1.5x 多档倍速自由调节。

### 5. 纯原生内联 SVG 与零 CORS 双击秒开
- 全站遵循严苛的 UI 图标规范，100% 采用精致的原生内联 `<svg>` 矢量图形，零外部字体库依赖、零系统 Emoji 按钮。
- 内置 `data/kaoyan_data.js` 离线全量数据包，彻底免疫浏览器在 `file:///` 本地文件协议下的 CORS 限制，双击即可直接秒开运行。

## 🚀 启动与使用指南

### 方式一：本地直接双击秒开（推荐 · 纯离线）
直接在本地文件管理器中，双击打开 [`index.html`](index.html)，即可瞬间加载全部 36 考点与音频，零配置、零等待。

### 方式二：本地 HTTP 服务
```bash
python -m http.server 8091
```
随后在浏览器中访问：`http://localhost:8091/index.html`。
